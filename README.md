# dt224g_alexandra_nilsson_uppg_3
Inlämningsuppgift 3


Denna uppgift består i att skapa startsidan till en fiktiv destination (Norrgläntan). 

**Syftet** är att öva på att skapa en mockup utifrån en given wireframe och sedan kunna skapa en hemsida från det. Vi ska använda semantisk HTML, strukturera sidans innehåll, använda grundläggande CSS, bli bättre på Flexbox/CSS Grid, lära oss mer om mobile-first, bli bättre på versionshantering och sedan publicera hemsidan. 


Detta ska enligt uppgiftsbeskrivningen finnas med/göras:  
>"Gemensamma krav för hela webbplatsen
Webbplatsen ska:
*	vara byggd med semantisk HTML,
*	webbplatsen ska följa grundläggande tillgänglighetsprinciper.
*	ha en tydlig och logisk rubrikstruktur,
*	använda CSS för att skapa en genomarbetad visuell design,
*	vara responsiv och fungera på både små och stora skärmar,
*	använda antingen Flexbox eller Grid i layouten,
*	vara uppbyggd enligt mobile-first,
*	innehålla minst en media query,
*	validera utan fel i W3C:s HTML-validator,
*	publiceras på en publik webbadress,
*	vara versionshanterad i ett GitHub-repo med tydlig commit-historik.
"
